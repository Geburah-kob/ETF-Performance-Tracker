# 📈 個人化 ETF 績效追蹤與視覺化系統

## 專案簡介
這是一個輕量級的桌面應用程式，專為學生與個人投資者設計。透過輸入股票代碼，系統能自動抓取歷史數據，並將股價走勢視覺化。本專案整合了 GUI 介面設計與 API 數據處理技術，解決市面上看盤軟體過於肥大且功能繁雜的問題。

## 技術與核心功能
* **GUI 介面開發**：使用 `tkinter` 打造簡潔直覺的視窗介面。
* **物件導向設計 (OOP)**：採用模組化架構，將 UI 邏輯與資料處理邏輯分離。
* **資料抓取與處理**：使用 `yfinance` 串接 Yahoo Finance API，即時獲取市場報價。
* **資料視覺化**：使用 `matplotlib` 繪製歷史收盤價折線圖，並無縫嵌入主視窗中。
* **防呆與例外處理**：具備完整的 `try-except` 機制，能有效攔截無效代碼輸入與網路中斷錯誤。

3. 執行程式：
